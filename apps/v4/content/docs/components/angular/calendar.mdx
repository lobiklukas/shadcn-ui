## Usage

```ts
import { Calendar } from "@/components/ui/calendar"
```

```html
<div uiCalendar mode="single" class="rounded-lg border"></div>
```

The Angular calendar is a native `Date`-math build of the same public shape as
the React `react-day-picker` wrapper — `mode`, `selected` (two-way), `month`
(two-way), `numberOfMonths`, `disabled`, `captionLayout`, `showWeekNumber`,
`weekStartsOn`, `fromDate`/`toDate` — with no `react-day-picker`/`date-fns`
dependency. Selection state follows `mode`: a single `Date`, a `Date[]`, or a
`{ from, to? }` range.

## Composition

```txt
<div uiCalendar>
├── nav buttons (previous / next month)
├── caption (label, or month + year dropdowns)
└── <table role="grid">
    ├── weekday headers (sr-only caption + scope="col")
    └── day cells (single Tab stop via roving tabindex)
```

## Booked Dates

Pass a `(date) => boolean` matcher to `disabled` to make specific days unselectable.

<Callout>
The React example also strikes booked dates through using DayPicker's
`modifiersClassNames`; the Angular build has no modifier API, so only the
disabled state renders.
</Callout>

## Custom Day Content

<Callout>
Not available in the Angular port. React customizes day cells through
DayPicker's `components.DayButton` render prop; the Angular build has no
per-day content hook, so the "$120 weekend price" example cannot be
reproduced. Extend `CalendarComponent` if you need it.
</Callout>

## Hijri Calendar

<Callout>
Not available in the Angular port. The React example uses
`react-day-picker/persian` for an Islamic (Hijri) calendar; the Angular grid
is built on the native Gregorian `Date` and has no alternate-calendar engine.
</Callout>

## RTL

To enable RTL support in Force UI, see the [RTL configuration guide](/docs/rtl).

Set `dir="rtl"` on the `[uiCalendar]` host; the navigation chevrons flip automatically.

## API Reference

This component is a Force UI original build (no upstream primitive); see the
`CalendarComponent` source for the full input list: `mode`, `selected`,
`month`, `numberOfMonths`, `showOutsideDays`, `showWeekNumber`,
`weekStartsOn`, `disabled`, `fromDate`, `toDate`, `captionLayout`,
`buttonVariant`.
